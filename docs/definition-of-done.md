# Definition of Done

> A story is **Done** when ALL of the following criteria are met.
> This list should be agreed upon by the whole team before Sprint 1 begins.

---

## Code Quality

- [ ] Code has been reviewed for readability, consistency, and correctness.
- [ ] Code follows project standards and avoids unnecessary hardcoded values.

## Testing

- [ ] All acceptance criteria have been tested and verified.
- [ ] Changes have been tested and introduce no known bugs.

## Documentation

- [ ] Relevant project documentation is updated to reflect any changes made.

## Version Control

- [ ] Changes are completed on a feature branch and merged into main through a Pull Request.
- [ ] Commit messages follow the Conventional Commits format.
